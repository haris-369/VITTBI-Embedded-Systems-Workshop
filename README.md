## Hardware Requirements
* Microcontroller (e.g., Arduino Uno / ESP32)
* LEDs, Resistors, Push Buttons
* Temperature Sensor (e.g., DHT11/LM35)
* Piezo Buzzer
* Breadboard and Jumper Wires

## Software Requirements
* [Arduino IDE](https://www.arduino.cc/en/software) (or specify the IDE used)

## Schematics and Wiring
Each project folder contains the specific source code. Ensure your components are wired according to the standard schematics discussed in the workshop before flashing the code. 

## How to Run
1. Clone this repository to your local machine.
2. Open the desired project folder and launch the `.ino` / `.cpp` file in your IDE.
3. Select the correct board and port in your IDE tools menu.
4. Compile and upload the code to your microcontroller.
